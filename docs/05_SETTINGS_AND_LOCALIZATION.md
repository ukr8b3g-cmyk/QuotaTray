# 05 設定・多言語仕様

## 1. 一般

- Windows起動時に自動起動：OFF
- 起動時表示：トレイのみ
- 更新間隔：1分（選択肢 1/2/5分）
- パネル表示時に更新：ON
- 通信失敗時に前回値を表示：ON
- 2回目起動時は既存インスタンスを前面へ

## 2. 表示

- テーマ：ダーク（初期）／ライト／システム
- アクセント：緑（初期）、青、水色、紫、オレンジ、モノクロ
- 透明度：100%（60～100）
- コンパクト／詳細パネル：×ボタンを押すまで表示を維持
- 常に手前：OFF
- 位置固定：OFF
- モニターと位置を記憶：OFF
- 画面端に吸着：OFF
- トレイ表示：円形ゲージ＋可能なら％
- 位置を中央へ戻す

透明度等はコンパクト・詳細パネルに共通適用。設定ウィンドウには適用しない。

## 3. 言語

初期：`自動（OS表示言語）`

対応：

- `ja-JP` 日本語
- `en-US` English
- `zh-Hans` 简体中文
- `zh-Hant` 繁體中文
- `ko-KR` 한국어
- `de-DE` Deutsch
- `fr-FR` Français
- `es-ES` Español
- `pt-BR` Português (Brasil)
- `ru-RU` Русский

未対応OS言語は英語。手動変更は画面を再構成して即時反映する。日付、時刻、曜日、数値はOSの地域設定を使用する。

## 4. 通知

初期値：

- 残り30%以下：OFF
- 残り10%以下：ON
- 通常リセット検出：OFF
- 予定外リセット候補：ON
- リセット券期限3日前：ON
- 接続失敗が15分継続：ON

同一条件の通知はクールダウンし、毎分繰り返さない。

## 5. 履歴

- 保存期間：365日
- 選択肢：90日／365日／無期限
- CSV書き出し
- JSON書き出し
- 履歴削除（確認必須）
- 保存フォルダーを開く

## 6. 接続

- Codex実行ファイル：自動／明示パス
- 検出バージョン
- App Server状態
- 認証状態（「ログイン済み／未ログイン」だけ。メール等は出さない）
- 再認証
- 公式インストール案内を開く
- 診断情報をコピー（機密情報を除外）

## 7. 情報

- QuantaTrainバージョン
- ライセンス
- PRIVACY
- GitHub Releaseを開く
- Codexを開く
- ChatGPTを開く
- 公式Codexドキュメント

## 8. 設定移行

設定ファイルには `schemaVersion` を持たせる。未知のキーは保持または安全に無視し、破損時はバックアップ後に既定値へ戻す。旧バージョンからの移行テストを用意する。

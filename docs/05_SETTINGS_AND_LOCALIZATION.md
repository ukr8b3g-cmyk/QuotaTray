# 05 設定・多言語仕様

## 1. 一般

- Windows起動時に自動起動：OFF
- 起動時表示：トレイのみ（ミニ／コンパクト／詳細を選択可能）
- 更新間隔：1分（選択肢 1/2/5分）
- パネル表示時に更新：ON
- 通信失敗時に前回値を表示：ON
- 2回目起動時は既存インスタンスを前面へ

## 2. 表示

- テーマ：ダーク（初期）／ライト／システム
- アクセント：緑（初期）、青、水色、紫、オレンジ、モノクロ
- 透明度：100%（60～100）
- ミニ／コンパクト／詳細パネル：明示的に切り替えるか隠すまで表示を維持
- 常に手前：OFF
- 位置固定：OFF
- モニターと位置を記憶：OFF
- 画面端に吸着：OFF
- ミニ表示のクリック透過：OFF（ミニだけが対象。コンパクト／詳細には適用しない）
- トレイ表示：円形ゲージ＋可能なら％
- 表示位置をリセット（全表示の共通位置を消去し、コンパクト表示をメイン画面中央へ戻す）
- すべての設定を初期化（赤いボタン、確認必須）

透明度はスライダー操作中にミニ・コンパクト・詳細パネルへ即時反映し、設定画面は常に不透明とする。
テーマとアクセントは選択直後に表示中のパネルとトレイメニューへ反映する。設定画面自体はコンボボックス処理中の再生成を避け、次回表示時に反映する。
設定画面はメインディスプレイ中央へモデルレス表示し、開いたままでもミニ・コンパクト・詳細を操作可能とする。表示切替時の位置継承は位置固定・位置記憶のON/OFFにかかわらず有効とする。

## 3. 言語

初期：`自動（OS表示言語）`

設定画面では独立カテゴリを設けず、「一般」に統合する。

対応：

- `ja-JP` 日本語
- `en-US` English
- `zh-Hans` 简体中文
- `zh-Hant` 繁體中文
- `ko-KR` 한국어
- `de-DE` Deutsch
- `fr-FR` Français
- `es-ES` Español
- `pt-BR` Português (Brasil)
- `ru-RU` Русский

未対応OS言語は英語。手動変更は表示中のパネルとトレイメニューへ即時反映し、設定画面自体は次回表示時に反映する。日付、時刻、曜日、数値はOSの地域設定を使用する。

## 4. 通知

初期値：

- 残り30%以下：ON（表示色はオレンジ）
- 残り10%以下：ON
- 通常リセット検出：ON
- 予定外リセット候補：ON
- リセット券期限3日前：ON
- 接続失敗が15分継続：ON

同一条件の通知はクールダウンし、毎分繰り返さない。

## 5. 履歴

- 保存期間：3年（1095日）
- 選択肢：1年／3年／5年／無期限
- CSV書き出し
- JSON書き出し
- 履歴削除（確認必須）
- 保存フォルダーを開く

## 6. 接続

設定画面では独立カテゴリを設けず、「詳細設定」に統合する。

- Codex実行ファイル：自動／明示パス
- 検出バージョン
- App Server状態
- 認証状態（「ログイン済み／未ログイン」だけ。メール等は出さない）
- 再認証
- 公式インストール案内を開く
- 診断情報をコピー（機密情報を除外）

## 7. 情報

- QuantaTrayバージョン
- クリック可能なGitHubリポジトリリンク
- ライセンス
- PRIVACY
- GitHub Releaseを開く
- Codexを開く
- ChatGPTを開く
- 公式Codexドキュメント

## 8. 設定移行

設定ファイルには `schemaVersion` を持たせる。未知のキーは保持または安全に無視し、破損時はバックアップ後に既定値へ戻す。旧バージョンからの移行テストを用意する。

## 9. 使用分析

- 使用メタデータ収集：初期OFF、明示的な有効化が必要
- 自動取得間隔：1分／5分（初期）／15分／30分／手動のみ
- 使用分析タブを開いた時に即時取得：ON
- 起動時：有効な場合に1回取得
- 走査は重複させず、通常は前回以降の追加分だけを読み取る
- `null`、欠損、破損したメタデータ行はスキップし、残りを継続する

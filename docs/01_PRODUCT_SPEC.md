# 01 製品仕様

## 1. 目的

QuantaTrayは、Codexの週間利用枠をWindowsタスクトレイから短時間で確認する読み取り専用モニターです。特に次を重視します。

- 現在の週間残量をすぐ確認できる
- 次回リセット日時を確認できる
- 利用可能なリセット券と期限を詳細画面で確認できる
- 予定外に残量が回復した履歴を残せる
- 常駐負荷とメモリ増加を抑える
- 認証情報・会話・プロジェクトファイルを扱わない

## 2. 主な利用シナリオ

### シナリオA：残量確認

ユーザーがトレイアイコンをクリックすると、キャッシュ値を即表示しながら最新値を取得し、週間残量と次回リセットを確認できる。

### シナリオB：詳細確認

コンパクト画面から詳細を開き、リセット券の件数・期限、最近のリセット履歴、プラン、接続状態を確認できる。

### シナリオC：常時表示

ユーザーが明示的に設定した場合だけ、ミニ、コンパクトまたは詳細パネルを画面に残し、透明度、最前面、位置固定、位置記憶、端吸着を利用できる。表示切替では同じモニターと基準位置を維持する。ミニ表示では、追加オプションとしてクリック透過を利用できる。

### シナリオD：予定外リセット確認

週間残量が予定日前に大幅回復し、リセット券の減少が確認されない場合、「予定外リセット候補」として観測時刻範囲を履歴に残す。

## 3. 機能範囲

### 必須

- タスクトレイ常駐
- 週間利用枠の残量
- 次回リセット日時とカウントダウン
- 60秒更新と即時更新
- リセット券件数・期限
- リセット履歴
- 多言語
- ダークテーマ
- 設定保存
- Windows自動起動オプション
- インストーラー版、ポータブル版

### 初版対象外

- リセット券使用
- 複数アカウント切替
- 使用量予測
- 5時間枠等の強制表示
- UIスクレイピング
- 自動更新
- クラウド同期
- macOS/Linux

## 4. 情報が取得できない場合

- 週間枠なし：取得不能を明示し、別枠を週間枠として偽装しない。
- リセット券詳細なし：`availableCount` の件数だけ表示。
- プランなし：プラン欄を非表示。
- App Serverなし：公式Codex CLIの導入案内。
- 未認証：公式ブラウザ認証。
- オフライン：前回値と古さを表示。

## 5. 非機能要件

- アイドル時CPU平均：実用上ほぼ0%に近いこと
- Poll処理：重複実行しない
- UI：キャッシュ表示は100ms以内を目標
- Appプロセスのワーキングセット：安定状態で100MB未満を目標（App Serverは別計測）
- 24時間で継続的なメモリ・ハンドル増加がない
- ネットワークリスナーを開かない
- 管理者権限を要求しない
- 高DPI、複数モニターに対応

# 02 UI/UX仕様

## 1. 全体方針

- 初期テーマ：ダーク
- 初期アクセント：グリーン
- Windows標準フォントを使用
- 連続アニメーションなし
- 角丸、余白、境界線で階層を表現
- 警告色はアクセント色と独立
- OpenAIロゴをアプリアイコンに使わない。独自の「Q＋ゲージ」案を使う

## 2. トレイアイコン

- 残量を円形ゲージで表現
- 高DPIで判読可能な場合のみ2桁％を重ねる
- 低DPIではリングのみ。Tooltipには必ず残量を表示
- Tooltip例：`QuantaTray — 週間残量 19% — 次回 7/29 09:00`
- 左クリック：コンパクト表示
- 右クリック：クイックメニュー
- ダブルクリック：詳細表示（任意、設定可能にしなくてよい）

## 3. ミニ表示

推奨サイズ：幅220、高さ95前後（論理ピクセル）。

- タイトルバー、閉じる、メニューボタンを表示しない
- `週間利用枠`、`残り`、残量率を同じ行に置き、横ゲージ、次回リセット日時と短縮カウントダウンだけを表示
- 次回リセットはラベルを小さくし、`2026/08/02 14:50 (6D19H)` のように1行表示
- ダブルクリックでコンパクト表示へ戻る
- 右クリックでコンパクト／詳細、更新、設定を開く
- クリック透過ON時は背後へマウス操作を通し、解除はトレイまたは設定から行う
- ミニ表示とクリック透過は初期OFF

## 4. コンパクト表示

推奨サイズ：幅240、高さ338前後（論理ピクセル）。

幅を維持し、次の3カードを縦方向に詰めて表示する：

1. ヘッダー
   - 独自アイコン
   - QuantaTray
   - 更新中／更新ボタン
   - 3点メニュー
   - 閉じる（トレイへ隠す）
2. 週間利用枠
   - `残り 19%`
   - 横ゲージ
   - 次回リセット日時と短縮カウントダウンを1行表示
3. リセット券
   - 利用可能件数
   - 最短の有効期限（小さくなりすぎない本文サイズ）
4. 最近のリセット履歴
   - 最新1件
   - 日時と分類を読みやすい本文サイズで2行表示
   - 詳細表示への導線

正常時の「最新の情報です」は表示せず、更新中または取得失敗時だけ状態を表示する。

## 5. 詳細表示

推奨サイズ：幅410前後、高さ560～680。画面に収まらない場合のみスクロール。

上から順に：

1. 週間利用枠
2. リセット券
   - 利用可能件数
   - 個別期限（返された分だけ）
   - `credits == null` の場合は件数だけ
   - 使用ボタンなし
3. 最近のリセット履歴
   - 直近3～5件
   - 色：通常緑、予定外候補黄、リセット券候補青、不確定灰
   - 「すべて表示」
4. その他
   - プラン（取得できる場合）
   - 接続状態
   - Codex App Serverバージョン
   - 最終更新

## 6. 3点メニュー

```text
ミニ表示 / 詳細表示 / コンパクト表示
今すぐ更新
常に手前に表示          ON/OFF
位置を固定              ON/OFF
表示位置をリセット
設定
Codexを開く
ChatGPTを開く
このアプリについて
終了
```

「常に手前」「位置固定」は直接切替可能。ただし初期OFF。

## 7. 設定画面

カテゴリ：

- 一般
- 表示
- 言語
- 通知
- 履歴
- 接続
- 情報

設定画面は透明度、最前面、位置固定の対象外。通常の不透明ウィンドウとして表示する。

## 8. 表示オプション

- テーマ：ダーク／ライト／システム
- アクセント：緑、青、水色、紫、オレンジ、モノクロ
- 透明度：60～100%、初期100%
- 常に手前：初期OFF
- 位置固定：初期OFF。ドラッグのみ禁止し、ボタン操作は可能
- 位置記憶：初期OFF
- 画面端吸着：初期OFF
- ミニ表示のクリック透過：初期OFF。ミニ表示だけを対象とする
- ミニ／コンパクト／詳細パネルはフォーカスを失っても閉じない
- 表示切替では位置固定・位置記憶の設定にかかわらず、同じモニターと基準位置を引き継ぐ
- 起動時表示：トレイのみ（初期）／ミニ／コンパクト／詳細

## 9. 位置記憶

- ミニ／コンパクト／詳細で共通のモニター、画面端アンカー、作業領域内の相対位置を保存
- DPI変更後も論理座標で復元
- 対象モニターが消えた場合はプライマリ作業領域中央へ退避して保存位置を更新
- タスクバーと重ならない
- 位置固定中でもトレイまたは設定から「表示位置をリセット」を実行可能
- 表示位置リセットは位置だけを初期化し、全設定の初期化は赤いボタンと確認画面で分離する

## 10. 色ルール

- 通常：選択アクセント
- 残り30%以下：黄
- 残り10%以下：赤
- 0%：濃赤
- 取得不能：灰

警告色はユーザーのアクセント選択に左右されない。

## 11. アクセシビリティ

- キーボード操作
- ToolTipとAccessibleName
- 100/125/150/200% DPI
- Windows高コントラスト時はカスタム色よりシステム色を優先
- 色だけで状態を伝えず、文字ラベルを併記

# 02 UI/UX仕様

## 1. 全体方針

- 初期テーマ：ダーク
- 初期アクセント：グリーン
- Windows標準フォントを使用
- 連続アニメーションなし
- 角丸、余白、境界線で階層を表現
- 警告色はアクセント色と独立
- OpenAIロゴをアプリアイコンに使わない。独自の「Q＋ゲージ」案を使う

## 2. トレイアイコン

- 残量を円形ゲージで表現
- 高DPIで判読可能な場合のみ2桁％を重ねる
- 低DPIではリングのみ。Tooltipには必ず残量を表示
- Tooltip例：`QuantaTrain — 週間残量 19% — 次回 7/29 09:00`
- 左クリック：コンパクト表示
- 右クリック：クイックメニュー
- ダブルクリック：詳細表示（任意、設定可能にしなくてよい）

## 3. コンパクト表示

推奨サイズ：幅340前後、高さ210前後（論理ピクセル）。

表示内容は週間枠だけ：

1. ヘッダー
   - 独自アイコン
   - QuantaTrain
   - 更新中／更新ボタン
   - 3点メニュー
   - 閉じる（トレイへ隠す）
2. 週間利用枠
   - `残り 19%`
   - 横ゲージ
   - 次回リセット日時
   - あと何日何時間
3. フッター
   - 最終成功時刻
   - 最新／更新中／古い情報／取得失敗
   - 詳細表示への導線

コンパクト画面には、リセット券、履歴、プランを表示しない。

## 4. 詳細表示

推奨サイズ：幅410前後、高さ560～680。画面に収まらない場合のみスクロール。

上から順に：

1. 週間利用枠
2. リセット券
   - 利用可能件数
   - 個別期限（返された分だけ）
   - `credits == null` の場合は件数だけ
   - 使用ボタンなし
3. 最近のリセット履歴
   - 直近3～5件
   - 色：通常緑、予定外候補黄、リセット券候補青、不確定灰
   - 「すべて表示」
4. その他
   - プラン（取得できる場合）
   - 接続状態
   - Codex App Serverバージョン
   - 最終更新

## 5. 3点メニュー

```text
詳細表示 / コンパクト表示
今すぐ更新
常に手前に表示          ON/OFF
位置を固定              ON/OFF
設定
Codexを開く
ChatGPTを開く
このアプリについて
終了
```

「常に手前」「位置固定」は直接切替可能。ただし初期OFF。

## 6. 設定画面

カテゴリ：

- 一般
- 表示
- 言語
- 通知
- 履歴
- 接続
- 情報

設定画面は透明度、最前面、位置固定の対象外。通常の不透明ウィンドウとして表示する。

## 7. 表示オプション

- テーマ：ダーク／ライト／システム
- アクセント：緑、青、水色、紫、オレンジ、モノクロ
- 透明度：60～100%、初期100%
- 常に手前：初期OFF
- 位置固定：初期OFF。ドラッグのみ禁止し、ボタン操作は可能
- 位置記憶：初期OFF
- 画面端吸着：初期OFF
- コンパクト／詳細パネルはフォーカスを失っても閉じず、×ボタンでだけトレイへ隠す
- 起動時表示：トレイのみ（初期）／コンパクト／詳細

## 8. 位置記憶

- モニターのデバイス名と作業領域内の相対位置を保存
- DPI変更後も論理座標で復元
- 対象モニターが消えた場合はプライマリ作業領域内へクランプ
- タスクバーと重ならない
- 位置固定中でも設定から「中央へ戻す」を実行可能

## 9. 色ルール

- 通常：選択アクセント
- 残り30%以下：黄
- 残り10%以下：赤
- 0%：濃赤
- 取得不能：灰

警告色はユーザーのアクセント選択に左右されない。

## 10. アクセシビリティ

- キーボード操作
- ToolTipとAccessibleName
- 100/125/150/200% DPI
- Windows高コントラスト時はカスタム色よりシステム色を優先
- 色だけで状態を伝えず、文字ラベルを併記

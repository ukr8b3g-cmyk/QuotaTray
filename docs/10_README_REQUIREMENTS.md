# 10 README必須記載

READMEには次を欠かさない。

## 必須

- QuantaTrainの概要
- OpenAI非公式・非提携
- 週間残量、リセット券、履歴の説明
- 読み取り専用で券を使用しない
- Codex CLI/App Serverが必要
- Codex Desktop画面は起動不要
- 既存Codex認証をApp Serverが再利用する
- 未認証時は公式ブラウザログイン
- ブラウザCookieや保存パスワードを直接読まない
- テレメトリー・広告・開発者サーバーなし
- 保存するローカルデータ
- 予定外リセットは推定である
- インストーラー／ポータブルの差
- 対応OSとx64
- 32bit非対応
- SmartScreen注意
- アンインストールとデータ削除
- トラブルシューティング
- ライセンスとThird-party notices

## 禁止表現

- 「完全オフライン」
- 「アカウント情報を一切利用しない」
- 「OpenAIが確実にリセットした」
- 「公式Codexアプリ」
- 「認証情報を使わない」

代わりに：

- 「開発者運営サーバーを持たないローカル中心設計」
- 「認証情報をQuantaTrainが直接取得・保存しない」
- 「予定外リセット候補」
- 「OpenAI非公式」

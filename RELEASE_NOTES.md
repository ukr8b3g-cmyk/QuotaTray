# QuantaTray v0.2.13

## 日本語

新しい正式版の公開をWindowsのトレイ通知でお知らせします。「設定」→「通知」→「新しいバージョンを通知する」をオンにして保存すると、起動中に24時間に1回、GitHubの正式リリースを確認します。初期設定はオフです。

通知は各バージョンにつき1回です。通知をクリックするか、トレイアイコンを右クリックして新しいバージョンの項目を選ぶと、該当するリリースページが開きます。ダウンロードとインストールは手動です。

v0.2.12以前をお使いの場合は、このページからWindows x64用インストーラーまたはポータブルZIPを入手してください。配布ファイルは `SHA256SUMS.txt` で照合できます。

## English

QuantaTray can notify you of new stable releases. In **Settings → Notifications**, turn on **Notify me about new versions** and save. This option is off by default. When enabled, QuantaTray checks GitHub once every 24 hours while running.

Each newer version is announced once. Click the notification or choose the new version from the tray icon’s right-click menu to open its release page. Download and install the update manually.

If you use v0.2.12 or earlier, get the Windows x64 installer or portable ZIP from this release to enable notifications for future versions. Use `SHA256SUMS.txt` to verify the download.

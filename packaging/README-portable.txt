QuantaTray portable

Run QuantaTray.exe from a writable folder. Settings, history, and redacted
logs are saved under the local data folder because portable.flag is present.
The self-contained .NET runtime may extract native files to a temporary
directory at launch; no separate .NET installation is required.

The official Codex CLI must be installed separately and signed in. QuantaTray
is unofficial and is not affiliated with OpenAI.

This build is unsigned. Verify SHA256SUMS.txt from the GitHub Release.
